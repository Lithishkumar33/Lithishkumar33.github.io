## 🌟 Interactive Features

- **Recruiter Fast-Track Dossier**: Instant snapshot toggling key recruiter facts (Notice Period: 0 Days, Location: Bengaluru, Preferred Roles, Target Stack).
- **Interactive REST API Inspector**: Live simulation testing endpoints from full-stack Django applications with dynamic JSON payload views and latency metrics.
- **Interactive SQL Query Runner**: Live table renderer demonstrating Window Functions (`DENSE_RANK`), Common Table Expressions (CTEs), and customer segment discount models.
- **Interactive Project Case Studies & Lightbox**: Deep architectural walkthroughs, database models, and engineering challenges.
- **One-Click Contact & Copy Toast**: Effortless copying of email and phone numbers.
- **Zero-Dependency & Blazing Fast**: Pure vanilla HTML/CSS/JS with 100/100 Lighthouse performance metrics.
